# Techno Bundle — نسخه ۱۰

اپلیکیشن وب فارسی و راست‌چین با قابلیت نصب PWA و استقرار روی GitHub Pages.

## استقرار
1. محتوای این پوشه را در ریشه مخزن GitHub Pages بارگذاری کنید.
2. در Settings → Pages، منبع استقرار را روی شاخه و پوشه ریشه (`/`) تنظیم کنید.
3. سایت را با HTTPS باز کنید؛ نصب PWA و Service Worker در محیط امن (HTTPS یا localhost) فعال می‌شود.

## فایل‌ها
- `index.html`: رابط کاربری و منطق محاسبات
- `manifest.webmanifest`: تنظیمات PWA
- `sw.js`: ذخیره فایل‌های اصلی برای استفاده آفلاین
- `icons/`: آیکون‌های نصب

## توجه مالی
نتایج، برآورد مدیریتی بر اساس فرمول‌های نمایش‌داده‌شده در بخش «فرمول‌ها» هستند. پیش از استفاده تجاری، تعریف سود و بودجه بازاریابی را با سیاست مالی سازمان تطبیق دهید. اطلاعات بسته‌ها در حافظه محلی همان مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام‌سازی نمی‌شوند.
